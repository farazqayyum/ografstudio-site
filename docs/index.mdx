OGraf Studio is an open-source, browser-based editor for EBU OGraf-compatible graphics:
lower thirds, scoreboards, tickers, full-screen graphics and reusable templates.

New to Studio? Start with the [how-to guides](/guides). They walk through installing Studio,
building a first graphic and exporting it for playout. The pages below are the full reference.

| Page | What it covers |
| --- | --- |
| [User guide](/docs/user-guide) | Every feature of Studio, from creating a template to exporting it, sorted by what you are doing |
| [AI authoring](/docs/ai-authoring) | The built-in AI Assistant, external MCP clients and the `ograf-authoring` skill |
| [Playback](/docs/playback) | How previews and exported graphics play frames, and the player API |
| [Shader plugins](/docs/shader-plugins) | Installing and building packs of GLSL shaders |
| [Animation plugins](/docs/animation-plugins) | Installing and building packs of entrance and exit animations |
| [Renderer plugins](/docs/renderer-plugins) | Versioned chart renderers and how Studio trusts them |
| [Development](/docs/development) | Running from source, the MCP server, standalone executables and verification |
| [Third-party credits](/docs/third-party) | Licences for the OGraf logo and other bundled assets |
